一分钟选型结论

RackNerd 产品线看着多，但对国内买家的决策其实只有三步：① 买特价年付还是标准月付　② 选哪个机房　③ 要不要 NVMe / Windows。三步定完，剩下的都只是配置堆叠。

2026 年最重要的两个变化（先看这两条再选）：
① 老促销全线下架，价格翻了近一倍。2025 黑五 1C1G 是 $10.60/年，2026 年 RackNerd 把年付 $20 以下的套餐全部下架，改卖 $21.99–$119.99 的 5 档。现在是最不适合入手的时点之一——不急就等黑五闪购（post-698123、post-744024）。
② 在售档位已经没有 DC02 了。社区公认最好的机房（联通 318 Mbps、74 段解锁）只存在于历史促销/闪购机型，官网 Location 选项里现在是 DC03 / 圣何塞 / 西雅图 / 达拉斯 / 纽约 / 芝加哥。

先说清三个前提：
① 没有中国大陆优化。RackNerd 走 AS36352（HostPapa / ColoCrossing），去程 Cogent、回程 Arelion / Cogent / Level3 混合，全程没有 CN2 GIA、9929、CMIN2。它便宜是因为「普通国际线路 + 低价硬件」，不是线路好（post-655249 原话：「没有优化 没有优化 没有优化」）。
② 官网有两套价目表：特价年付（5 档，$21.99/年起）和 标准 KVM（7 档，月付 $17.99 起）。同样内存，标准档年付价是特价档的 3–10 倍，先看清再下单。
③ 本页结论优先用 NodeSeek 一手实测：148 篇帖子 / 2,120 条评论里能贴出原始数字的句子，逐条挂了 post id；本机 ping 只用于机房之间横向比较，不代表国内体验（见 测试 IP）。

三条硬结论：
① 联通 > 电信 > 移动。原话「联通>电信>移动，联通电信直连够用了，移动存在部分地区阻断」（post-655334）。
② DC02 是分水岭，但已经买不到。联通晚高峰单线程 318 Mbps（post-582179）、电信回程 170–190 ms 稳定（post-902453）、74 段 IP 解锁好（post-234019）——这些说的都是 DC02，而 2026-11 官网在售档位已无 DC02。
③ 现在的最优解是 DC03 或圣何塞。DC03 延迟一百多 ms、电信/联通都能用；圣何塞 2026 年货源最稳，但社区明确「移动别选圣何塞」（post-235900）。

为什么特价档比标准 KVM 便宜这么多？

因为这是两套完全独立的价目表，不是「打折」。特价档是 RackNerd 常年挂在首页 / LET 的引流款，配置刻意做低（SSD 更小、流量算法不同），价格压到极致；标准 KVM 是官网目录价，走的是「随时可买、可选周期」的常规售卖逻辑。

2026 年的新情况：两套价目表的相对关系没变，但特价档本身涨价了。原来 $10–18 的老促销在 2026 年被全部下架，换成 $21.99 起的新五档（post-698123）。 社区的说法是「升级配置涨价了，鸡荒连厂家都涨价」（post-744024）。所以「特价档 = 便宜」这个结论仍然成立，但便宜的幅度已经小了一半。

另一个容易踩的误区：RackNerd 的长周期基本不给折扣。KVM-1/2/4GB、Windows 全系、独服的年付价正好等于月付 × 12，季付 = 月付 × 3，一分不省；只有 Ryzen 全系年付约 9 折（10.8 个月的钱买 12 个月）。所以「年付更划算」在这里不成立——省下来的钱全部来自特价档本身的定价。

常见问题

RackNerd 和 ColoCrossing（CC）是什么关系？
RackNerd 是独立商家（RackNerd LLC，2019 年成立，总部加州），机房与网络大量使用 ColoCrossing 的资源，IP 归属 AS36352（HostPapa / ColoCrossing）。 这解释了两件事：为什么价格能压这么低（用的是 CC 的存量机房和老平台硬件），以及为什么线路是普通国际线路（CC 本身不做中国优化）。
特价年付和标准 KVM 到底差在哪？
差在三件事：计费周期（特价只有年付 / 两年付，标准支持月付到年付）、配置（1 GB 档：特价 20 GB SSD + 3 TB 流量，标准 50 GB SSD + 1 TB 流量）、价格（同内存年付价差 3–10 倍）。 它们不是同一个商品的折扣关系，而是两套独立上架的产品，所以不存在「等特价打折买标准档」这种玩法。
续费会涨价吗？
促销档的卖点就是「续费同价」——社区里几乎每篇促销帖都会标这句（post-739277、post-494895）。 极少数人反馈续费时价格变了，通常是活动档被下架后按新价续。 稳妥做法：加进购物车后看清 Billing Cycle 里年付那一行的金额和续费说明，以购物车实际显示为准，别只看首页大字。本文所有价格都是官网抓取时点的目录价。
有中国大陆优化线路吗？会不会偶尔走 CN2？
没有。全线走 Cogent / Arelion / Level3 这类普通国际线路，去程电信 163、联通 4837、移动 CMI，回程同样不保证。 历史上有过个别促销批次出现类似 CN2 的路径，但那是偶发，不能当买点。要 CN2 GIA / 9929 / CMIN2 请找专门做优化的商家。
买了之后能换机房吗？
特价年付档通常不能免费换机房，标准档也要看库存和工单沟通结果。所以「先 ping 测试 IP 再下单」是最省钱的一步——换机房比换机器麻烦。 部分独服机型直接写明「Deployed in First Available US Datacenter Location」，下单前必须发工单指定，否则随机分配。
不过有两条确定的宽松政策：① 购买 3 天内可以免费换一次 IP（解锁/被墙都能提，post-513584）；② 机房迁移可以提工单，有人从圣何塞迁到 DC03 成功，但 IP 不保留（post-290126）。
IPv6 怎么开？
默认只给 IPv4。洛杉矶、犹他、多伦多、斯特拉斯堡、都柏林这几个机房可以开工单免费申请原生 IPv6（VPS 最多 100 个，独服 /64）。 开工单时写明 VPS 主 IP 和用途即可，一般几十分钟内回复。
支持支付宝吗？退款呢？
支持支付宝、银联、PayPal、信用卡和加密货币，国内买没有障碍。 退款比想象中宽松：社区有实例——$21.99 年付用掉一段时间后开工单，按剩余天数比例退回到账户余额，余额无限期有效（post-799341）。 但注意两点：① 退的是账户余额，不是原支付渠道；② 能不能退、退多少取决于工单沟通，官方 TOS 并没有承诺无理由退款。想留退路的还是买月付。
IP 被墙了怎么办？
低价 VPS 的通病，RackNerd 的 IP 段里确实混有被滥用的地址。社区验证过的做法：
① 开机先查 IP 段：74.x 段（尤其 DC02 的 74.48.*）解锁漂亮，ChatGPT / Netflix / TikTok / Amazon PV 都能过，部分数据还判家宽（post-595913、post-234019）。
② 3 天内免费换一次 IP：工单说清「解锁不理想 / 被墙」即可（post-513584）。
③ 被「送中」（谷歌系跳验证码 / 无法访问 Gemini）：申请 IPv6 走 IPv6 出站，或上 WARP / 一键修送中脚本（post-655334）。
要求 IP 长期干净的，这个价位给不了保证。
性能到底怎么样？能跑什么？
社区融合怪（NodeQuality）实测的典型值：
· CPU：E5-2697 v2 / Xeon Gold 5118 这类老平台，GB5 单核 750–784、多核 1400–1566；超售严重的宿主机单核会掉到 400 左右（post-219013、post-234019）。
· 内存：读写约 16 GB/s 读 / 12.6 GB/s 写，明显低于现代 DDR4（50 GB/s），是老平台的典型表现。
· 磁盘：SSD RAID-10，顺序读写数百 MB/s 到 1 GB/s 级，4K 随机一般；Ryzen 线的 NVMe 明显更好。
结论：老平台 CPU + 共享 vCPU，适合建站、Docker 轻应用、代理、跑脚本；不适合长期满载（会被限速）、不适合跑分党、不适合对单核敏感的编译。
适合建站吗？
轻量站可以（个人博客、企业展示站、日几千 PV），WordPress + 缓存插件在 2 GB 档上跑得动。 但要接受两点：晚高峰下载带宽波动大（实测 3–52 Mbps 区间），以及没有 SLA 保障。真要商用，建议前面套 Cloudflare，或者干脆双机冗余。

选购注意事项与已知风险

下单前必看

① 先 ping 再买：测试 IP 见上一节，晚高峰再测一次。
② 确认机房：特价档只有 4 个机房，圣何塞 / 芝加哥 / 亚特兰大要走 Ryzen 或 Windows 线。
③ 确认周期与续费价：购物车里核对年付金额，别只看首页。
④ 支付方式：支付宝可用，付款后一般几分钟内自动开通。
⑤ 开机后立刻做：改 root 密码 → 开防火墙 → 装 BBR → 测 IP 是否被墙。

已知风险（按重要性排）：
1. 超售：$20/年的价格必然对应高密度宿主机，晚高峰 CPU steal 和 IO 会抖。
2. 晚高峰下载掉速：延迟通常稳，但下载方向会掉；DC03 联通有抖动/丢包记录（post-499338），DC02 反而稳到 318 Mbps（post-582179）。
3. 涨价已成事实：2026 年老促销全下架，1C1G 从 $10.60 涨到 $21.99（post-698123），且新档配置没提升多少。
4. 「最佳机房」可能买不到：DC02 不在售，圣何塞/DC03 经常缺货；官网显示有货≠你下单时还有货。
5. 二手市场有溢价：老闪购机型（$7.99–$13.88）在社区被「溢价 100–300 元」收（post-46166、post-681327），带邮箱转让有账号风险。
6. aff 内容极多：NodeSeek 上大部分「补货/促销」帖都带 AFF，有的只讲优点。本页把结论和证据帖分开列，便于自己核对。
7. IP 声誉参差：低价吸引滥用用户，买前测、买后 3 天内换。
8. 价格与库存会变：本文所有数字是 2026-11-02 的快照。
9. 移动用户避雷：社区原话「移动存在部分地区阻断」（post-655334），圣何塞「移动别选」（post-235900）。
